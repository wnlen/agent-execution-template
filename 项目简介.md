• 当前这个项目的效果可以概括成一句话：                                                                                                    
                                                                                                                                          
  把 AI Coding Agent 从“聊天式执行”，变成“有安装、有边界、有验收、有记录的任务执行流程”。                                                 
                                                                                                                                          
  它解决的核心问题不是“让 AI 更聪明”，而是让 AI 在真实项目里更可控、更少打扰人、更容易复盘。                                              
                                                                                                                                          
  用户能做到什么                                                                                                                          
  用户在任意项目里运行：                                                                                                                  
                                                                                                                                          
  npx ai-execution-template init                                                                                                          
                                                                                                                                          
  然后只改两个文件：                                                                                                                      
                                                                                                                                          
  ai/project/project.md   # 项目稳定背景                                                                                                  
  ai/project/task.md      # 当前任务                                                                                                      
                                                                                                                                          
  再让 Codex / Claude Code / Cursor 读：                                                                                                  
                                                                                                                                          
  ai/template/prompt.md                                                                                                                   
                                                                                                                                          
  Agent 会按协议执行任务，最后写：                                                                                                        
                                                                                                                                          
  ai/project/result.json                                                                                                                  
  ai/project/result.md                                                                                                                    
  ai/project/metrics.json                                                                                                                 
                                                                                                                                          
  也就是说，用户不需要每次重新解释项目、不需要写一大段 prompt、不需要靠聊天记录追踪结果。                                                 
                                                                                                                                          
  它解决的问题                                                                                                                            
                                                                                                                                          

    1. 任务边界漂移                                                                                                                         


  以前用户说“修一下登录”，AI 可能到处搜、乱改、扩大范围。                                                                                 
                                                                                                                                          
  现在任务必须经过：                                                                                                                      
                                                                                                                                          
  readiness gate                                                                                                                          
  risk gate                                                                                                                               
  permission boundary                                                                                                                     
  acceptance check                                                                                                                        
                                                                                                                                          
  没有目标、范围、权限、验收，就应该 blocked，而不是硬做。                                                                                
                                                                                                                                          

    2. 项目上下文重复输入                                                                                                                   


  以前每次都要告诉 AI：                                                                                                                   
                                                                                                                                          

  - 项目是什么                                                                                                                            
  - 技术栈是什么                                                                                                                          
  - 哪些文件能动                                                                                                                          
  - 哪些地方危险                                                                                                                          
  - 怎么验证                                                                                                                              
                                                                                                                                          

  现在这些被拆到：                                                                                                                        
                                                                                                                                          
  ai/project/project.md                                                                                                                   
  ai/project/runtime.md                                                                                                                   
  ai/project/refs/                                                                                                                        
                                                                                                                                          
  AI 每次按协议读取，不靠人反复口述。                                                                                                     
                                                                                                                                          

    3. 模板升级会覆盖用户内容                                                                                                               


  现在明确分区：                                                                                                                          
                                                                                                                                          
  ai/template/  # 协议区，可 update 覆盖                                                                                                  
  ai/project/   # 项目现场，用户专属                                                                                                      
                                                                                                                                          
  update 只更新：                                                                                                                         
                                                                                                                                          
  ai/template/**                                                                                                                          
                                                                                                                                          
  绝不改：                                                                                                                                
                                                                                                                                          
  ai/project/**                                                                                                                           
                                                                                                                                          
  这解决了模板产品最关键的信任问题。                                                                                                      
                                                                                                                                          

    4. AI 执行结果不可审计                                                                                                                  


  现在每次执行后必须有：                                                                                                                  
                                                                                                                                          
  result.json   # 机器可读事实记录                                                                                                        
  result.md     # 人类可读总结                                                                                                            
  metrics.json  # 模型、耗时、成功、复用潜力                                                                                              
                                                                                                                                          
  这让一次 AI 执行不再只是聊天输出，而是可检查、可归档、可复盘的任务记录。                                                                
                                                                                                                                          

    5. 不知道项目是否安装正确                                                                                                               

  现在有：                                                                                                                                
                                                                                                                                          
  npx ai-execution-template doctor                                                                                                        
                                                                                                                                          
  它会检查关键文件，输出：                                                                                                                
                                                                                                                                          
  [OK]                                                                                                                                    
  [WARN]                                                                                                                                  
  [MISSING]                                                                                                                               
                                                                                                                                          
  并显示模板版本。                                                                                                                        
                                                                                                                                          
  当前版本定位                                                                                                                            
  当前 v0.7 已经是：                                                                                                                      
                                                                                                                                          
  可安装的 AI 执行协议 npm 包雏形                                                                                                         
                                                                                                                                          
  它不是：                                                                                                                                
                                                                                                                                          
  AI Agent 平台                                                                                                                           
  多 Agent 调度器                                                                                                                         
  自动代码执行器                                                                                                                          
                                                                                                                                          
  它是更底层的东西：                                                                                                                      
                                                                                                                                          
  AI Agent 在项目里工作的文件协议和安全边界                                                                                               
                                                                                                                                          
  真正的价值                                                                                                                              
  它把 AI 执行从这类模式：                                                                                                                
                                                                                                                                          
  人类反复解释 -> AI 随机执行 -> 聊天里看结果                                                                                             
                                                                                                                                          
  变成：                                                                                                                                  
                                                                                                                                          
  npx 安装协议 -> 人类填少量任务信息 -> AI 按协议执行 -> 结果落盘 -> 可验证可复盘                                                         
                                                                                                                                          
  一句话总结：                                                                                                                            
                                                                                                                                          
  这个项目让便宜或强大的 AI Agent 都能在同一套项目协议下工作，减少人类输入，保护项目现场，并留下可验收的执行记录。                        
                                                                                                                                          
  本轮没有改文件，所以没有提交推送命令。
